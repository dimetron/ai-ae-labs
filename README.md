# AI Agents Engineering — лабораторні та домашні завдання

Репозиторій із кодом для курсу **AI Agents Engineering** (Prometheus): стартові
шаблони лабораторних робіт, умови домашніх завдань, приклади з вебінарів і демо-проєкти.
Матеріали відкриваються **потижнево** — папка нового тижня з'являється тут після
відповідного вебінару.

**Go 1.27 · `google.golang.org/adk/v2 v2.4.0`** (ADK вимагає Go ≥ 1.26.6) — станом на 09/2026.

## Як працювати з репозиторієм

1. **Зробіть власну копію.** Найпростіше — клонувати й викласти у свій репозиторій
   (fork публічного репозиторію не можна зробити приватним):

   ```bash
   git clone https://github.com/dimetron/ai-ae-labs.git
   cd ai-ae-labs
   git remote rename origin upstream
   git remote add origin git@github.com:<ваш-акаунт>/ai-ae-labs.git   # ваш порожній репозиторій
   git push -u origin main
   ```

   Коли відкриється наступний тиждень: `git pull upstream main`.

2. **Перевірте, що все збирається** (без ключів і без мережі):

   ```bash
   go build ./... && go test ./...
   ```

3. **Ключі провайдерів** читаються з `apps/.env` (шаблон — `apps/.env-example`) або зі
   змінних оточення; змінна оточення має пріоритет. Перший знайдений провайдер виграє:

   | Змінна | Провайдер |
   |---|---|
   | `OLLAMA_BASE_URL` | локальний Ollama через OpenAI-сумісний ендпоінт (`OLLAMA_MODEL` — модель) |
   | `GOOGLE_API_KEY` | Gemini (`GEMINI_MODEL` — модель) |
   | `OPENAI_API_KEY` | OpenAI (`OPENAI_MODEL` — модель) |

   Кожна лаба друкує, який провайдер вона обрала і чому.

4. **Запуск лаби** — з кореня репозиторію (у інструкціях, де написано
   `cd courses/AI_Agents_Engineering/lectures`, просто лишайтеся в корені):

   ```bash
   go run ./week1/Day1_Models_and_Frameworks_Landscape/labs
   ```

## Структура

```
week<N>/<День>/labs/        стартовий шаблон лаби + README з покроковою інструкцією
week<N>/<День>/Homework.md  умова домашнього завдання, критерії оцінювання, формат здачі
internal/                   спільні helper-пакети (adkenv, fakellm, labrun)
examples/                   приклади з вебінарів — окремий Go-модуль, по тижнях
demo/                       демо-проєкти курсу (agentgateway, knowledge graph, evals, …)
```

## Здача домашнього завдання

- Виконане завдання — у **вашому** репозиторії; у форму здачі — посилання на нього.
- Репозиторій може бути приватним — тоді додайте акаунт ментора в collaborators
  (акаунт указано в інструкції до курсу на платформі).
- `go build ./...` і `go test ./...` мають проходити.
- Дедлайн — два тижні після відкриття завдання; рекомендуємо виконати та надіслати
  протягом тижня.

## Джерело

правки робіть у своїй копії, а помилки в стартових шаблонах — повідомляйте на
форумі курсу.
